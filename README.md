# 简易干燥盒

基于 STC8H1K17T 的小型加热干燥盒项目，包含外壳模型、电路资料和固件。项目仍处于原型验证阶段；现有固件针对**第一版实装 PCB**，请先核对接线并完成无负载测试，再连接加热片。

## 当前固件

- OLED 显示温度和运行状态，按键设定目标温度（30～80 ℃）及倒计时（5～180 分钟）。
- 加热输出采用 5 秒周期的时间比例控制；温度远低于设定值时全功率输出，接近设定值时使用待实测整定的 PID 参数。
- NTC 读数异常、温度达到 85 ℃、倒计时结束或人工停止时关闭加热；故障锁定后需检查硬件并重新上电。
- **这一版不接风扇。**原风扇接口 H2 改作加热输出，H3 不可接加热片。第一版 PCB 的原理图库引脚映射与实装芯片不一致，详见[固件接线和验收说明](firmware/oled_test/README.md)。

## 编译

安装 PlatformIO 后，在 `firmware/oled_test` 目录执行：

```sh
platformio run
```

生成文件位于 `.pio/build/oled_test/firmware.hex`。编译通过仅说明固件可构建，不代表温控精度或实物安全已验证。

## 使用前检查

1. 核对实装芯片型号、H2 接口极性、加热片额定电压和功率，以及电源、驱动器件和 PCB 走线的承载能力。
2. **先断开加热片**，按[固件说明](firmware/oled_test/README.md)验证待机、运行、停止和 NTC 故障状态下的驱动电压。
3. 为加热片设置独立于单片机的软件之外的温度保护，并检查外壳材料的耐热性。
4. 记录实际升温和超调曲线，再整定 PID 参数；不要将当前参数视为已经验证的恒温性能。
