# 干燥盒固件：H2 改作加热输出

本版适用于实装 `STC8H1K17T-33I-SOP20` 的第一版 PCB。原理图库的左侧引脚映射与实装芯片不一致，必须以实装芯片和实测线路为准。

## 关键接线

- OLED：U2 物理 3/4 脚，实际为 P1.6/P1.7，分别驱动 SDA/SCL。
- 蜂鸣器：U2 物理 2 脚，实际为 P1.5，经 Q3 驱动。
- **加热片只可接 H2（原风扇接口）**：U2 物理 5 脚，实际为 P1.3，经 R4、Q1 驱动。
- **H3 不可接加热片**：其 Q2 控制网络接 U2 物理 6 脚，该脚在实装型号上是 TCap，不是 GPIO。
- 不再连接风扇；也不要同时在 H2 接风扇和加热片。

本文件中的引脚结论源于实装芯片型号、原理图、PCB 网络和 OLED 引脚电压实验。PCB 上 `P1.6_fan`、`P1.7_ptc` 是旧原理图库产生的**网络名称**，不是实装芯片相应物理脚的功能。

## 当前控制方式

- 上电及待机时加热输出关闭。长按 SW1 启动设定的倒计时。
- 低于设定温度 5℃ 及以上时，H2 加热输出 **100% 导通**；接近设定温度时，按固定点 PID 计算 0～100% 的加热占空比。OLED 显示 `HEAT xxx%`（平均输出比例，不是瞬时开关状态）。
- 采用 5 秒周期的时间比例控制，而不是高频 PWM；每秒更新一次 PID。超过设定温度 2℃ 时强制停止加热。PID 系数只是保守起始值，必须记录实测升温/超调曲线后再整定，不能保证第一次就精确恒温。
- NTC 首次异常读数即关闭输出；运行中发生异常或温度达到 85℃ 时锁定 `FAULT` 并报警，需检查硬件后重新上电。
- 倒计时到 0 或人工停止时立即关闭输出。设置温度 30～80℃，时间 5～180 分钟。
- OLED 左侧竖线修正：上电清除控制器全部 132 列显存。

## 接负载前的必要验收

1. 加热片先保持断开，仅用 USB 为板供电并烧录固件。
2. 待机时测 Q1 栅极对地应接近 0V；启动且当前温度明显低于设定温度时应接近 3.3V；停止或断开 NTC 后应回到 0V。
3. 确认 H2 两脚的极性和负载连接，且加热片的**实际**额定电压、电流/功率与 Q1、D1、H2、PCB 走线以及 5V 电源的额定能力相容。项目最初方案写的是 5V/5W，但它不能替代实物铭牌核对。
4. 加热片应另有独立于单片机的温度保护（例如适当温度的热熔断器），并远离不耐热的外壳材料。仅靠软件故障保护不足以防范 MCU 死机或 MOSFET 短路。

## 充电宝供电注意

待机约 30 秒后整板熄灭、Type-C 电压跌到约 1.6～1.7V，而加热时正常，符合充电宝低负载自动断电的表现，但需用稳定 5V 电源交叉验证。PID 恒温时也可能出现长时间低占空比或 0% 输出，充电宝仍可能自动断电；固件**不会为保活而强行加热**。需要可靠的长时间运行时，选不会自动断电的 5V 电源或明确支持低电流模式的移动电源。
